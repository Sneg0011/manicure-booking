# Лунка: онлайн-запись в студию маникюра

Демонстрационный проект для портфолио. Клиент сам выбирает услугу, мастера и свободное время, получает личную ссылку и может перенести или отменить запись. Менеджер видит записи в панели, управляет расписанием и звонит только тем, кому нужно.

> **Это демо.** Студия, мастера и записи вымышленные, настоящие услуги не оказываются. Не вводите настоящие имена и телефоны: на форме записи есть кнопка «Подставить тестовые данные».

## Что умеет

**Клиент**

- видит услуги, цены по мастерам, работы и ответы на частые вопросы;
- записывается только на действительно свободное время;
- получает экран подтверждения и личную ссылку без пароля;
- переносит запись до 3 раз и отменяет её не позже чем за 2 часа до визита;
- при желании подключает Telegram-бота и управляет записью там.

**Менеджер** (вход по логину и паролю)

- смотрит календарь на день и неделю по двум мастерам;
- создаёт запись по звонку, переносит и отменяет, отмечает «пришла» и «не пришла»;
- звонит по списку «Позвонить» и ставит отметку «Менеджер предупредил»;
- меняет часы работы, закрывает время, правит услуги, цены и правила записи;
- видит сводку и журнал всех уведомлений с ошибками отправки.

**Мастер** получает уведомления в Telegram и смотрит свои записи на сегодня и завтра.

## Стек

Next.js 16, React 19, TypeScript, PostgreSQL, Drizzle, grammY. Тесты: Vitest и Playwright на настоящем PostgreSQL.

## Как устроено

| Папка | За что отвечает |
|---|---|
| `src/booking` | Свободное время, создание, перенос, отмена, «Позвонить», сводка |
| `src/notifications` | Кому что отправить, журнал, отправка |
| `src/bot` | Telegram-бот для клиентов и мастеров |
| `src/auth` | Пароль менеджера и сессия |
| `src/admin` | Клиенты, журнал, расписание, услуги |
| `src/demo` | Демо-данные и ежедневный сброс |
| `src/app` | Страницы сайта и панели |

Два решения, которые стоит посмотреть:

- **Двойная запись запрещена самой базой.** На таблице `bookings` стоит ограничение на пересечение интервалов у одного мастера (`drizzle/0001_no_overlap.sql`). Проверка в интерфейсе нужна только для удобства, поэтому два одновременных запроса не могут занять одно время. Тест: 20 параллельных записей, одна успешная.
- **Сессия проверяется в каждом действии панели.** Все действия менеджера проходят через `managerAction` (`src/auth/session.ts`), поэтому повтор запроса без входа ничего не меняет, даже если адрес действия известен.

Время всегда считается по Москве. Ошибка отправки уведомления не отменяет запись: она видна в журнале, а клиент попадает в список «Позвонить».

## Запуск на своём компьютере

Нужен Node.js 24. Docker и отдельный PostgreSQL не нужны: база запускается из npm-пакета.

**1. Установите зависимости**

```bash
npm install
```

**2. Создайте файл настроек**

```bash
cp .env.example .env.local
```

В PowerShell вместо `cp` используйте `Copy-Item .env.example .env.local`.

**3. Заполните в `.env.local` вход менеджера**

Придумайте логин и укажите его в `MANAGER_LOGIN`. Получите хэш пароля и вставьте его в `MANAGER_PASSWORD_HASH`:

```bash
npm run hash-password -- "ваш пароль"
```

Получите случайные строки для `SESSION_SECRET` и `CRON_SECRET`, выполнив эту команду по одному разу на каждую:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

**4. Запустите базу в отдельном терминале и оставьте его открытым**

```bash
npm run db:start
```

**5. В другом терминале создайте таблицы и демо-данные**

```bash
npm run db:seed
```

Команда полностью заменяет данные в базе демонстрационными.

**6. Запустите сайт**

```bash
npm run build
```

```bash
npm run start
```

Откройте http://localhost:3100, панель менеджера находится на http://localhost:3100/admin/login. Для разработки вместо двух команд выше подойдёт `npm run dev`.

## Telegram без настоящего бота

Для проверки есть заглушка Telegram API: она записывает сообщения и умеет отвечать ошибкой. Запустите её в отдельном терминале:

```bash
npm run telegram:stub
```

Укажите в `.env.local` значения:

```
TELEGRAM_BOT_TOKEN=123:LOCAL
BOT_USERNAME=lunka_demo_bot
TELEGRAM_API_ROOT=http://127.0.0.1:54321
```

Отправленные сообщения видны на http://127.0.0.1:54321/__messages.
