# Размещение

Эта инструкция размещает демо бесплатно: база на Neon, сайт на Vercel. Для настоящих клиентов такая схема не подходит, об этом в последнем разделе.

Пароли и токены вводите только в настройках сервисов и в свои локальные файлы `.env.seed` и `.env.deploy`: git их не видит. Никому их не отправляйте.

## 1. База на Neon

1. Зарегистрируйтесь на https://neon.com и создайте проект. Регион выберите **Frankfurt (AWS eu-central-1)**: он ближе всего к серверу сайта и к России.
2. В разделе подключения скопируйте две строки:
   - **с пулом** (в адресе есть `-pooler`): запишите в новый файл `.env.deploy` как `DATABASE_URL=...`;
   - **прямую** (без `-pooler`): запишите в новый файл `.env.seed` как `DATABASE_URL=...`.

## 2. Таблицы и демо-данные

Выполните это на своём компьютере один раз. Файл `.env.local` менять не нужно, локальный сайт останется на своей базе.

```bash
npx tsx --env-file=.env.seed scripts/seed.ts
```

Команда создаёт таблицы и заполняет базу демо-данными. Той же командой база возвращается к исходному демо.

## 3. Секреты

Все значения из этого шага и из шага 4 записывайте в `.env.deploy` в виде `ИМЯ=значение`, без пробелов и кавычек.

Получите случайные строки для `SESSION_SECRET`, `CRON_SECRET` и `TELEGRAM_WEBHOOK_SECRET`, выполнив команду по одному разу на каждую:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

Для `MASTER_1_INVITE` и `MASTER_2_INVITE` используйте более короткую строку:

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
```

Придумайте логин и пароль менеджера и получите хэш для `MANAGER_PASSWORD_HASH`:

```bash
npm run hash-password -- "ваш пароль"
```

## 4. Бот в Telegram

1. Откройте @BotFather в Telegram и отправьте команду `/newbot`.
2. Выберите имя и адрес бота. Адрес без @ это `BOT_USERNAME`, полученный токен это `TELEGRAM_BOT_TOKEN`.

Без бота сайт и панель тоже работают, этот шаг можно пропустить. Тогда на сайте не будет кнопки подключения бота, а мастера не получат уведомления: в журнале будет статус «Бот не подключён».

## 5. Сайт на Vercel

1. Отправьте проект в свой репозиторий на GitHub и зарегистрируйтесь на https://vercel.com.
2. Импортируйте репозиторий. Настройки сборки менять не нужно. Регион `fra1` и ежедневная задача уже указаны в `vercel.json`.
3. Скопируйте всё содержимое `.env.deploy` и вставьте в поле Key в разделе Environment Variables: Vercel сам разобьёт текст на строки. Если не разбил, нажмите **Import .env**. Должно получиться 11 переменных:

| Переменная | Откуда |
|---|---|
| `DATABASE_URL` | Строка Neon с пулом |
| `MANAGER_LOGIN` | Ваш логин |
| `MANAGER_PASSWORD_HASH` | Шаг 3 |
| `SESSION_SECRET` | Шаг 3 |
| `CRON_SECRET` | Шаг 3 |
| `DEMO_MODE` | `true` |
| `TELEGRAM_BOT_TOKEN` | Шаг 4 |
| `BOT_USERNAME` | Шаг 4 |
| `TELEGRAM_WEBHOOK_SECRET` | Шаг 3 |
| `MASTER_1_INVITE`, `MASTER_2_INVITE` | Шаг 3 |

4. Запустите развёртывание и откройте адрес вида `имя-проекта.vercel.app`.

**Адрес `*.vercel.app` открывается не всегда.** В замере 2026-11-07 с одного подключения он то обрывался, то работал, и чужие сайты на этом домене вели себя так же. Сайты на Vercel со своим доменом при этом отвечали. Для теста и показа через VPN или видео этого достаточно.

Если ссылку будут открывать люди без VPN, подключите свой домен: в проекте **Settings → Domains** добавьте адрес, создайте у регистратора запись DNS, которую покажет Vercel, и повторите команду из шага 6 с новым адресом. Код менять не нужно. На настоящем домене этот путь не проверялся, поэтому после настройки откройте сайт через мобильный интернет.

Бесплатный тариф Vercel разрешает только некоммерческое использование: личному портфолио это подходит, а для рекламы услуг условия нужно перепроверить.

## 6. Подключение бота к сайту

Выполните на своём компьютере:

```bash
npx tsx --env-file=.env.deploy scripts/set-webhook.ts https://имя-проекта.vercel.app
```

Откройте по одной ссылке с аккаунта каждого мастера, подставив свои значения:

```
https://t.me/<BOT_USERNAME>?start=master_<MASTER_1_INVITE>
https://t.me/<BOT_USERNAME>?start=master_<MASTER_2_INVITE>
```

Бот ответит «Вы подключены как мастер». Эти ссылки держите в секрете: в панели их нет намеренно.

## 7. Проверка после размещения

1. Откройте сайт с домашнего интернета и с мобильного интернета в России.
2. Запишитесь с тестовыми данными и проверьте запись в панели.
3. Проверьте, что мастер получил сообщение в Telegram.
4. Проверьте журнал в панели: там не должно быть статуса «Ошибка».
5. В разделе Cron Jobs настроек Vercel запустите ежедневную задачу вручную. Демо-данные должны обновиться, а привязка мастеров сохраниться.

На бесплатном тарифе Vercel задача выполняется раз в сутки с точностью до часа, около 3:00 МСК. На бесплатном тарифе Neon база останавливается после простоя и запускается за доли секунды при первом запросе.

## Что изменить для настоящих клиентов

Это ориентир, а не юридическая консультация. Перед запуском сверьте требования с актуальной редакцией 152-ФЗ и разъяснениями Роскомнадзора.

**Закон и данные**

- Разместить базу и сервер в России: данные граждан РФ нельзя собирать и хранить в зарубежных базах. Neon и Vercel для этого не подходят.
- Оформить оператора данных: это владелец бизнеса, а не разработчик.
- Подать уведомление в Роскомнадзор до начала сбора данных.
- Добавить политику обработки данных и отдельное согласие на странице записи, без отмеченной заранее галочки.
- Если передавать данные через Telegram, указать это в политике: сервера мессенджера находятся за рубежом.
- Настоящие реквизиты в подвале.

**Система**

- Удалить `DEMO_MODE` и демо-данные: иначе данные будут стираться каждую ночь.
- Убрать пометки о демо, кнопку тестовых данных и вымышленные адрес и телефон.
- Настроить резервные копии базы.
- Хранить в базе хэш личной ссылки, а не саму ссылку.
- Подключить настоящую отправку уведомлений клиентам: SMS или email, сейчас в демо только экран, журнал и бот.
- Поставить платные тарифы или свой сервер: на бесплатных тарифах нет гарантий доступности.
- Сменить пароль менеджера и все секреты, завести отдельный вход для каждого сотрудника, если их станет больше одного.

**Содержание**

- Настоящие фотографии работ вместо снимков со стока: сейчас снимки не показывают работы студии.
- Настоящие цены, услуги, мастера, адрес и договор с клиентом.
