# Направление дизайна

Статус: ждёт одобрения заказчика. Снимки лежат рядом с этим файлом.

## Идея

Студия называется «Лунка»: так называют светлый полумесяц у основания ногтя. Название занимает всю ширину первого экрана, а полумесяц становится формой кнопок времени: свободное время показано рядом ногтей, выбранный закрашивается лаком.

Живая деталь первого экрана: ближайшее свободное время берётся из базы и меняется от визита к визиту.

## Что выпало и что изменено

Использован скилл design-taste-frontend, направление `name-as-monument`, seed 1858698963.

| Что выпало | Что взято | Почему |
|---|---|---|
| Шрифты Gambarino и General Sans | Tenor Sans и Golos Text | В выпавших шрифтах нет кириллицы. Tenor Sans выбран сравнением с Unbounded и Sofia Sans Extra Condensed |
| Палитра Frost and slate (голубая) | Пропорции сохранены, цвета из предмета | Цвет этого предмета: красный лак |
| Меню справа | Меню слева | Справа пальцы на фото, меню теряется |
| Смешение текста `difference` в разделе мастеров | Сплошной цвет | Правило скилла |

## Токены

```css
--bg: #f9f5f5;      /* фон */
--surface: #f1e5e3; /* панели, свободные ногти */
--ink: #241417;     /* текст */
--muted: #6a5659;   /* второстепенный текст */
--polish: #b0112a;  /* лак: главное действие, выбранный ноготь, поле услуг */
--paper: #fbf7f6;   /* текст на тёмном и красном */
```

Шрифты подключаются локально, без внешних сервисов.

## Запреты заказчика

Тёмный slate с градиентными карточками, эмодзи-иконки, крем с терракотой, антиква с одним курсивным словом, моно-надписи прописными, тонкие линии-разделители, «→» в кнопках, бегущая строка, вращающийся бейдж.
