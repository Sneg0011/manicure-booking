# Направление дизайна

Статус: третье обновление 2026-11-07, заказчик утвердил. Сначала он одобрил первый экран и попросил сделать остальные разделы по его примеру, а фото заменить на молодые руки, затем принял всю страницу. Заменяет нюдовую версию с нарисованным ногтем. Первое направление «имя как монумент» заказчик отверг раньше.

Снимки лежат в `final/`.

## Откуда это

| Референс заказчика                     | Что взято                                                                                          |
| -------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Частный самолёт, тёмный экран          | Слово вокруг объекта, волна ткани внизу, круглая кнопка записи в кольце, выноска с точкой и линией |
| Розовый автомобиль                     | Огромное слово с градиентом за объектом, чередование тёмных разделов, идея конфигуратора с цветами |
| Природа, светлая страница              | Панель поиска под первым экраном, карточки с чипом и ссылкой, крупные фото со скруглением          |
| Прошлые: рука с жемчугом, sodanails.ru | Рука как главный образ, вкладки прайса, кнопка-капсула со стрелкой                                 |

Приёмы взяты, тексты, изображения и фирменный стиль не копируются.

## Идея

Рука с жемчугом стоит перед огромным словом ЛУНКА, как объект на постере. Посетитель примеряет цвет: на настоящем фото меняется цвет ногтей, а вместе с ним градиент слова и свечение фона. Форма ногтя с лункой остаётся у кнопок времени на странице записи.

Живые данные первого экрана: ближайшее свободное время и цена маникюра берутся из базы.

## Правила каждого раздела

Все публичные страницы тёмные. Каждый раздел строится как первый экран: огромное слово с градиентом на всю ширину, вырезанная рука поверх него, свечение фона, цены цветом шампань. Выбранный на первом экране цвет перекрашивает слова и свечение всей страницы. Текст никогда не лежит поверх слова или фото. Волна ткани поднимается там, где нужно спрятать край снимка, и не закрывает текст и кнопки.

## Как устроена примерка

Три слоя одного кадра в `public/photos`, без смешивания режимов, поэтому результат одинаков во всех браузерах:

1. `hero-hand.webp`: вырезанная рука.
2. Цветной блок с маской `hero-nails-mask.webp`.
3. `hero-nails-light.webp`: блики и тени ногтей поверх цвета.

Цвет «Нюд» показывает исходное фото без слоёв.

## Токены

Добавлены к прежним:

```css
--night: #120c0e; /* тёмные разделы */
--night-2: #1d1418; /* карточки на тёмном */
--champagne: #e2c6a0; /* значения в выносках */
```

Прежние светлые токены и шрифты остаются: Prata для заголовков, Jost для текста, подключены локально через `@fontsource`.

## Разрешено референсами заказчика

Заказчик сам привёл это в примерах, поэтому правила скиллов здесь не действуют: антиква, градиент в буквах, тёмные разделы, волна ткани, линии между строками прайса.

## Запрещено

Эмодзи вместо иконок, стекло, нумерация 01/02/03, моно-шрифт, чужие логотипы и марки на снимках, выдуманные отзывы и статистика.
