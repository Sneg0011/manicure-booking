# Направление дизайна

Статус: одобрено заказчиком 2026-11-07. Заменяет первое направление «имя как монумент», которое заказчик отверг.

Макеты: `preview/nude.html` (главная), `preview/nude-book.html` (выбор времени). Снимки лежат рядом с этим файлом.

## Откуда это

Референсы заказчика: прайс с длинным ногтем вместо буквы, прайс на бетонной стене, рука с жемчугом на сером фоне, сайт-визитка мастера маникюра. Сайт sodanails.ru заказчик назвал как пример. Приёмы взяты, тексты, изображения и фирменный стиль не копируются.

| Откуда | Что взято |
|---|---|
| Референс с длинным ногтем | Ноготь стоит в названии между буквами, нюдовая гамма, антиква, подпись с разрядкой, строки прайса с описанием и линиями между ними |
| Рука с жемчугом | Рука как главный образ, спокойный светлый фон |
| Сайт-визитка мастера | Галерея работ, частые вопросы |
| sodanails.ru | Кнопка-капсула со стрелкой в кружке, вкладки прайса, колонки цен по мастерам |

## Идея

Студия называется «Лунка»: так называют светлый полумесяц у основания ногтя. Длинный глянцевый ноготь с лункой стоит в названии между буквами «ЛУ» и «НКА». Кнопки времени имеют форму ногтя с лункой, выбранная закрашена.

Живая деталь первого экрана: ближайшее свободное время берётся из базы.

## Токены

```css
--bg: #e8e0d7;      /* основной фон */
--surface: #f3ede6; /* светлые разделы и панели */
--stone: #d9cfc3;   /* круг на первом экране */
--deep: #2a211c;    /* кнопки, подвал */
--ink: #231c18;     /* текст */
--muted: #74675d;   /* второстепенный текст */
--line: #c9bdb0;    /* линии прайса */
--rose: #9c4f6b;    /* главное действие, выбранный ноготь */
--paper: #fbf7f2;   /* текст на тёмном */
--nail: #f6e3d6;    /* свободный ноготь */
```

Шрифты: Prata (заголовки), Jost (текст). Подключаются локально через `@fontsource`, без внешних сервисов.

## Разрешено референсами заказчика

Заказчик сам привёл это в примерах, поэтому правила скилла здесь не действуют: антиква, линии между строками прайса, подпись с разрядкой, градиенты в рисунке ногтя.

## Запрещено

Эмодзи вместо иконок, тёмный slate с градиентными карточками, стекло, нумерация 01/02/03, моно-шрифт, чужие логотипы и марки на снимках.
